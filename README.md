# 1万分の1 高専版

全国58高専の実在の学科から受験先を選び、寮と赤点と部活の5年間、就職、そして最期まで生きる高専生の人生シミュレーション。単一HTML。

- 出生地は都道府県別の出生数で決まり、中学で偏差値を上げて高専を受験する
- 公立高専（都立産技・大阪公立・神戸市立）は、その都府県で生まれた人だけが受験できる（ゲーム上のルール）
- 力の配分、部活の予算、将来の夢、留学、海外大学、就職から老後まで
- 実績図鑑・UR人生図鑑・チャレンジ・人生スコア・人生の種

## 公開

GitHub Pages: Settings → Pages → Branch `main` / folder `/ (root)`。

## データの出典

国立高専の学科・コースは令和9年度 国立高専 学生募集要項、公立・私立は各校の公表情報。出生地は人口動態統計2024の都道府県別出生数、偏差値は受験ラボの一覧の最高値を目安にした。女子学生比率と求人倍率は国立高専機構の資料。各校の校風や名物部活の描写、確率、年収はゲーム上の設定。
